# BeatBox - My Music Player

A simple beginner-friendly music player made with HTML, CSS and a little JavaScript.

## Files

- index.html
- style.css
- script.js
- images/
- music/

## How to run

1. Open this folder in VS Code.
2. Open index.html.
3. Use Live Server, or open index.html directly in a browser.
4. Keep the images and music folders in the same place.

## Beginner customization

To add a song, copy a .song-card in index.html and change:

- data-title
- data-artist
- data-image
- data-audio

Then put the new image in images/ and audio file in music/.
